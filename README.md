# Task Manager

A lightweight task management web app built with HTML, CSS, and JavaScript. Features include adding, deleting, and marking tasks as complete, filtering tasks by status, real-time search, and persistent storage using localStorage.

🔗 **Live Demo:** [task-manager-delta-azure-64.vercel.app](https://task-manager-delta-azure-64.vercel.app/)

## Features
- Add, delete, and complete tasks
- Filter tasks (All / Active / Completed)
- Search functionality
- Data persists using LocalStorage
- Fully responsive design
